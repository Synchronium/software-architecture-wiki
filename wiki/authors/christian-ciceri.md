# Christian Ciceri

**Books in this wiki:** [[sources/software-architecture-metrics]] (editor; contributing author, ch. 5)

## Background

Software architect and consultant with experience spanning both technical architecture and DevOps cultural transformation. Editor of *Software Architecture Metrics* (O'Reilly, 2022).

## Core Positions

Software architecture should be approached scientifically — measurements and metrics provide the empirical basis for architectural decisions. The "ownership shift" antipattern (DevOps becoming a separate automation team isolated from development) is a primary threat to delivery quality; the private build is the key remediation tactic. Trunk stability must be established before architectural metrics can be meaningfully evaluated.
